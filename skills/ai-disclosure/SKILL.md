# AI disclosure

The user uses AI ethically and wants every disclosure to read that way: calm and confident, written as a student who used a tool well, never as a confession.
**Soft in tone, accurate in content.** Softening changes how the help is framed. It never removes help that happened.

## The policy it must satisfy
**The course's own AI policy decides.** If the user hasn't shared it, ask for the syllabus language before drafting, or say plainly which assumptions you used. Many graduate psychology programs ask for something like this:
- **Every submission discloses**, whether AI was used or not. Some courses deduct points for a missing disclosure.
- **Cite the tool in APA**: `Claude (Anthropic, <year>)`.
- **Often allowed:** brainstorming, narrowing a topic, refining a question, outlining, grammar checks, slide layout and visuals.
- **Usually not allowed:** generating a draft, posts or sources wholesale. **Content and wording must be the student's.**
- **Placement options:** a footnote, a line in the introduction, or an appendix of prompts and outputs.
- **No AI used:** "No generative AI was used in preparing this submission."
- Different courses in the same program can have different policies. When the user names a course whose policy you haven't seen, ask for it.

## Steps
1. **Inventory the real help** from this conversation, or from what the user describes, in plain categories:
   - checking scores, facts or formatting
   - finding or verifying sources
   - reviewing notes, transcripts or the rubric
   - feedback on clarity and grammar
   - suggested revisions to wording
   - formatting and layout
2. **Map each item to soft wording** (table below). Group the items into one or two sentences. Don't list every section.
3. **Close with ownership** that is true. Use "the analysis, interpretations, and final content are my own." Say "all writing is my own" **only** if Claude suggested no wording.
4. **Offer placement**: footnote for a light touch, introduction line for papers, appendix only if the instructor asks for prompts.
5. **Give the user the draft to approve.** Insert it into a file only if they say to.

## Soft wording map
| What happened | Write |
|---|---|
| Brainstormed or talked through ideas | "to talk through my thinking" / "to brainstorm" |
| Checked scores, conversions, citations | "to check my … for accuracy" |
| Found or verified sources | "to help locate and verify sources" |
| Compared drafts to the rubric | "to compare my drafts against the rubric" |
| Suggested sentence rewrites | "to suggest revisions, which I reviewed and incorporated at my discretion" |
| Grammar and APA | "to check grammar and APA formatting" |
| Formatting or layout | "with formatting" (leave it out for pure document mechanics, like signature lines) |

## Tone rules
- **First person, active voice:** "I used…", never "AI was used…"
- **Lead with judgment:** "reviewed," "decided," "at my discretion."
- **Don't use apologetic or defensive words:** "only," "merely," "just," "I promise," "to be transparent."
- **Two to four sentences.** Plain and warm.
- **Never understate.** If Claude wrote or rewrote sentences the user kept, say Claude suggested revisions. If help went past the course policy (wholesale drafting), say so plainly to the user before drafting the disclosure, so they can decide what to do.

## Template
> I used Claude (Anthropic, <year>) to [help 1], [help 2], and [help 3]. [If wording was suggested: Claude also suggested revisions for clarity, which I reviewed and incorporated at my discretion.] The [analysis / clinical reasoning / interpretations] and final content of this [paper/report] are my own.

Add the APA reference when the paper has a reference list. Fill in the current year and the model the user actually used:
`Anthropic. (<year>). Claude (<model name>) [Large language model]. https://claude.ai`
